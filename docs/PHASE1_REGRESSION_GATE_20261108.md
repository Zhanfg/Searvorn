## 架构决策
- 保留 Rust Core + Kotlin/SAF + Capability VFS，解析器不得直接获得全局文件路径权限。
- Root/Shizuku/SAF/系统权限作为不同能力后端；统一接口不代表统一权限。
- 特权后端使用基于文件描述符的逐级解析，避免检查路径与使用路径之间的 TOCTOU。
- APK 签名块解析、证书展示、完整密码学验签为三个独立能力。
- 默认流式读取、限制输入规模与解析预算；不对不可信文件执行代码。
